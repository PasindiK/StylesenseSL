Direct Answer to "ensemble > each individual model?"
-----------------------------------------------------
For this current run: NO.
- RF-only accuracy (0.9412) is higher than ensemble accuracy (0.8824).
- Ensemble is higher than LR-only, but not higher than RF-only.

Interpretation
--------------
This is expected in some datasets/runs: even an RF-heavy ensemble does not
always beat the strongest single model. Ensemble can improve robustness, but
accuracy gain is data-dependent.

Recommendation for Fair Thesis Reporting
----------------------------------------
- Report all three metrics transparently (LR, RF, Ensemble).
- Use larger test sets and repeated-split averages for final claims.
- If needed, tune weights (instead of fixed defaults) on validation data.
