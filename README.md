# Apparel Domain Spring Boot Application

This project is a starter Spring Boot application for managing apparel products. It includes basic REST API endpoints for CRUD operations on products.

## Features
- Spring Boot 3.x
- Maven build
- RESTful API for product management
- Placeholder for future enhancements (categories, inventory, orders)

## Getting Started
1. Ensure you have Java 17+ and Maven installed.
2. Build the project:
   ```shell
   mvn clean install
   ```
3. Run the application:
   ```shell
   mvn spring-boot:run
   ```
4. API will be available at `http://localhost:8080/api/products`
